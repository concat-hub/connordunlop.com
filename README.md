# connordunlop.com

Personal website for Connor Dunlop. Hosted on GitHub Pages.

## Design direction

- **Inspiration:** Asterisk magazine — minimalist, text-forward, generous whitespace, no visual clutter
- **Not:** academic/stuffy, vibe-coded-looking, Lucid brand
- **Tone:** clean, readable, quietly confident. Should feel polished to a techy audience without trying too hard
- **Typography:** sans-serif, clear hierarchy, large titles, light body weights
- **Colors:** neutral base (white/off-white), black text, one or two subtle accent colors
- **Layout:** single-column, generous margins and spacing, no grid gimmicks

## Site structure

1. **Hero / Landing** — name, one-liner, current role, contact links
2. **About** — 2-3 paragraphs, conversational (not CV blurb)
3. **Work** — current + selected past roles, not a full CV dump
4. **Publications & Writing** — papers, op-eds, referenced work. Room for future blog posts
5. **Projects** — living list of current things (Lucid, Verifiable Compute Foundation, Newspeak House platform, GovAI supervision)
6. **Reading** — currently reading / recently read, pulled from Goodreads (RSS feed + client-side parsing)
7. **CV** — downloadable PDF link + rendered HTML version

## Tech

- Plain HTML/CSS (no framework)
- GitHub Pages hosting
- Custom domain: connordunlop.com
- Goodreads integration via RSS feed for reading list
